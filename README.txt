FriendSpace starter

Open index.html in a browser to preview.
This starter has a demo signup, local profile, post feed, and likes.
Data is stored locally in your browser only. There is no server, secure authentication,
real messaging, image uploads, or multi-user functionality yet.

To publish: upload index.html to a static website host such as Netlify or GitHub Pages.
The next development step is a real backend for accounts, posts, comments, messaging,
moderation, and shared data across users.
